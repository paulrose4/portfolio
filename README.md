Recruiting-oriented portfolio deployed with GitHub Pages.

## Local preview

The site uses static HTML, CSS and JavaScript. Open `index.html` directly or run any static file server.

## Public evidence policy

- Project metrics must be reproducible from source code, tests or versioned reports.
- Offline evaluation results are not presented as online accuracy.
- PostgreSQL/Qdrant/Redis integration tests are described separately from the default test baseline.
- Stale or environment-unbound evaluation artifacts are not shown as current passing evidence.
- Screenshots must not expose sensitive vertical-business content, customer PII, secrets or private operational data.
